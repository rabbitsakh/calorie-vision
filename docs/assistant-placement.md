# AI‑ассистент: размещение для всех

## Сейчас (гибридный shell 3.1.x)

| Где | Кто | URL / действие |
|-----|-----|----------------|
| **Композер на «Сегодня»** | любой залогиненный | поле текста / фото / **+** → AI и добавление еды |
| Меню аватара → AI‑ассистент | любой | `/assistant` |
| Старый `/admin/assistant` | редирект | → `/assistant` |

Таббар: **Сегодня · Зал · Прогресс · Я** (`/ration`, `/workouts`, `/stats`, `/profile`).  
План недели еды — `/plan`, вес — `/weight` (не вкладки).  
Алиасы: `/today` → рацион, `/progress` → стат, `/me` → профиль.

API: `/api/assistant`, `/api/assistant/stream`, `/api/assistant/apply` — `requireSession`.

## Почему так

1. AI рядом с записью еды на главном экране дня, без пятой вкладки.
2. «+» остаётся привычным входом в добавление.
3. Чат — отдельный экран; confirm-first для записей в дневник / зал / покупки.

## Умеет писать

Рацион (фото всегда с confirm + правка КБЖУ/порции), правка и удаление приёмов из стрима, план зала по дням (только после CTA — без silent stream write), покупки, вода, вес, старт сегодняшней; undo-стек; режимы Еда/Зал/Неделя; retry если «Добавляю» без записи; офлайн-баннер; rate-limit на chat/apply.

## Deep links

- `/assistant?mode=week&q=…` — недельный режим + префилл
- Пуш `weekly` → `/plan#week-digest`
- Пуш `reactivation` → `/assistant?mode=week`

## Не делать

- Публичный ассистент без авторизации
- Убирать «+» совсем (еда должна оставаться в один тап)
