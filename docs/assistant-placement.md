# AI‑ассистент: размещение для всех

## Сейчас (E2)

| Где | Кто | URL / действие |
|-----|-----|----------------|
| **Таббар — сдвоенная центр-кнопка** | любой залогиненный | слева **AI** → `/assistant`, справа **+** → меню добавления |
| Меню аватара → AI‑ассистент | любой | `/assistant` |
| Старый `/admin/assistant` | редирект | → `/assistant` |

Таббар: `Стат · Рацион · [AI | +] · Зал · Профиль`.

API: `/api/assistant`, `/api/assistant/stream`, `/api/assistant/apply` — `requireSession`.

## Почему E2

1. AI в основном chrome, без 5-й вкладки.
2. «+» остаётся на том же месте по привычке (правая половина).
3. Чат — отдельный экран; добавление еды — прежний sheet.

## Умеет писать

Рацион (фото всегда с confirm + правка КБЖУ/порции), план зала по дням (только после CTA «В план зала» — без silent stream write), покупки, вода, вес, старт сегодняшней; undo-стек; режимы Еда/Зал/Неделя; retry если «Добавляю» без записи; офлайн-баннер; rate-limit на chat/apply.

## Deep links

- `/assistant?mode=week&q=…` — недельный режим + префилл (Wave E)
- Пуш `weekly` → `/plan#week-digest`
- Пуш `reactivation` → `/assistant?mode=week`

## Не делать

- Публичный ассистент без авторизации
- Убирать «+» совсем (еда должна оставаться в один тап)
