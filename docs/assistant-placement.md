# AI‑ассистент: размещение для всех

## Сейчас (после этой волны)

| Где | Кто | URL |
|-----|-----|-----|
| Меню аватара (шапка) → **AI‑ассистент** | любой залогиненный | `/assistant` |
| Старый `/admin/assistant` | редирект | → `/assistant` |
| Таббар / кнопка «+» | **нет** | не засоряем основные 4 вкладки |

API: `/api/assistant`, `/api/assistant/stream`, `/api/assistant/apply` — `requireSession` (не только админ).

## Почему так

1. **Аватар** — уже место для вторичных инструментов (профиль, зал). Без 5-й вкладки и без конкуренции с фото/штрихкодом в «+».
2. **Отдельный экран** — длинный чат и режимы не влезают в sheet.
3. **Общий доступ** сразу после логина; админ-гейт снят с продукта, оставлен только на `/admin/*`.

## Дальше (продукт)

1. Короткий онбординг при первом заходе («Я вижу дневник и зал»).
2. Точка входа со сцены дня: тихая ссылка «Спросить ассистента» под кольцом (не в первом viewport).
3. Лимиты rate-limit на `/api/assistant*` per user (защита GigaChat-квоты).
4. Опционально: deep-link из пуша «Что ещё съесть?» → `/assistant?mode=food`.

## Не делать

- 5-я вкладка в MobileTabBar
- Пункт в меню «+» рядом с камерой
- Публичный ассистент без авторизации (контекст — персональные данные)
