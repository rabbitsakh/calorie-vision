# Дизайн-система Calorie Vision

Один набор токенов на всё приложение. Светлая и тёмная темы — это одни и те же имена переменных на `:root`. Тёмная включается через `prefers-color-scheme: dark`, без отдельного класса на экране.

Эталоны: зал 3.7.2 (крупные цели касания, одна сцена, тёмная тема вместе со светлой) и карточка «Сегодня» 3.7.3 (`MomentHeroCard`): бровь, число, `tabular-nums`, акцент без аварийного красного.

## Типографика

Текст — Manrope (`--font-body`). Крупные имена экрана — Unbounded (`--font-display`). Числа везде `tabular-nums`, чтобы «2 244» не прыгало.

| Роль | Токены |
| --- | --- |
| Бровь | `--type-eyebrow-size` 11 px, вес 800, трекинг 0.08 em, верхний регистр, цвет `--accent-ink` |
| Число героя | `--type-hero-size` 1.05 rem, вес 800, межстрочный 1.25, одна строка |
| Кнопка | `--weight-button` 700 |
| Поле | 16 px, чтобы телефон не увеличивал страницу при фокусе |

Класс `.ds-eyebrow` и `.ds-num` повторяют эти правила.

Светлая тема остаётся кремовой с бирюзой. Тёмная берёт палитру зала и макета карточки «Сегодня».

| `--card` | `#ffffff` | `#13211e` |
| `--surface-mist` | `#eef6f2` | `#1b2e2a` |
| `--muted` | `#5a635c` | `#b7c7c0` |
| `--muted-strong` | `#2c3530` | `#d7e7e1` |
| `--accent` | `#0d7377` | `#1aa6a6` |
| `--accent-soft` | `#d4f0ec` | `#163e3c` |
| `--accent-ink` | `#0f5c5e` | `#b7f3ec` |

| Углеводы | `#0891b2` | `#3ec6e0` |

`--accent` — ссылки, шкалы, иконки. `--accent-fill` — заливка кнопки с белым текстом. В тёмной теме яркий `#1aa6a6` читается на фоне, но белая подпись на нём не дотягивает до WCAG AA, поэтому кнопка остаётся тёмно-бирюзовой.

Состояния:

| Токен | Смысл |
| --- | --- |
| `--warn` / `--warn-soft` / `--warn-ink` | предупреждение, не авария |
| `--danger` / `--danger-ink` | текст ошибки |
| `--danger-fill` / `--on-danger` | необратимое действие (удалить аккаунт) |
| `--scrim` | затемнение под листом |
| `--shadow-card` | одна тень карточки |
| `--shadow-sheet` | тень нижнего листа |

Обычное действие не красится в `--danger`. «Сообщить об ошибке» — тихая строка списка.

Контраст текста на фоне карточки и фона не ниже WCAG AA (4.5:1 для обычного кегля). Белый на `--accent-fill` — около 5.6:1. `--muted` на `#101816` — около 10:1. `--accent-ink` на `--accent-soft` в тёмной теме — около 9:1.

## Движение

`--motion-fast` 180 мс, `--motion` 200 мс, кривая `--motion-ease`. При `prefers-reduced-motion: reduce` длительности обнуляются, а общее правило в `globals.css` гасит анимации.

## Компоненты

Классы и React-обёртки в `src/components/ds/ui.tsx` используют одни токены. Старые имена (`.btn`, `.card`, `.chip`, `.field`, `.scene-empty`, `.gym-sheet`) смотрят в те же переменные, поэтому уже собранные экраны не собираются заново.

| Компонент | Класс | Поведение |
| --- | --- | --- |
| Карточка | `.ds-card` / `.card` | радиус 26 px, рамка `--border-quiet`, одна тень, фон `--card` |
| Кнопка | `.ds-btn--primary` | высота 56 px, заливка `--accent-fill`, белый текст |
| Кнопка | `.ds-btn--secondary` | фон `--accent-soft`, текст `--accent-ink` |
| Кнопка | `.ds-btn--danger` | только удаление и другие необратимые шаги |
| Чип | `.ds-chip` | высота 44 px, таблетка; включённый — `--accent-fill` |
| Поле | `.ds-field` | высота 56 px, рамка `--border-quiet`, фон `--card` |
| Строка | `.ds-row` | высота от 56 px, заголовок и тихий hint |
| Пусто | `.ds-empty` | пунктир, короткий текст, одно действие |
| Лист | `.ds-sheet` / `.gym-sheet` | снизу экрана, фон `--card`, поверх `--scrim` |

На экране одна основная кнопка. Второе действие — вторичная кнопка, чип или текст `--accent-ink`.

## Тёмная тема

Переменные переопределяются на `html` при `prefers-color-scheme: dark`. Фон страницы, герой дня, зал, вкладки, композер, листы, `/try` и `/go` читают эти переменные. Кремовые заливки, которые были записаны как `#fff` или `rgba(255, 252, 248, …)`, переведены на `--card` и `--surface-chrome`. Утилиты Tailwind `bg-white`, `bg-amber-50`, `bg-red-50`, `text-slate-*` в тёмной теме тоже садятся на токены.

Листы больше не кладут светлую вуаль `--accent-ink` поверх экрана: подложка — `--scrim`.

## Вода

На экране вода пишется литрами с запятой: `0,7 из 2,5 л`. Кнопка добавления — `+0,25 л`. Функции только для показа: `formatWaterOf`, `formatWaterLiters`, `formatWaterDelta` в `src/lib/water-display.ts`. Поле цели в профиле по-прежнему принимает миллилитры — так устроен API — и рядом показывает, как эта цель выглядит на экранах.
