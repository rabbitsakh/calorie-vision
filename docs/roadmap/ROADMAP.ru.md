## Принципы приоритизации

1. **VPS = source of truth.** Любая фича → PR → `main` → деплой. Локальные правки без PR не считаются сделанными.
2. **RuStore отставать не должен.** После заметного релиза веба — APK + listing в том же цикле.
3. **Confirm-first.** AI не пишет молча в дневник / зал / покупки.
4. **Local-first на APK.** Холодный старт из бандла; сеть — для синка и AI.
5. **Релизы, не рой PR.** Собирать темы в один релизный PR/ветку; версию поднимать при релизе, не в каждом микро-фиксе. **Мерж — решение человека**, не агента.
6. **Точность > фичи.** Правки пользователя и датасет важнее новых экранов.
