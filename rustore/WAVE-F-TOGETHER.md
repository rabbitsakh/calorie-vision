## 1. Тексты (5 мин)

1. Открыть `rustore/listing.ru.md`.
2. В Консоли → Информация о приложении:
   - **Что нового** — блок «Что нового» из файла (AI + офлайн-очередь).
   - **Полное описание** — вставить обновлённый блок с **AI-ПОМОЩНИК** (если ещё нет).
3. Сохранить черновик (ещё не отправлять на модерацию).

## 3. Сборка и загрузка APK

После merge волн A–E в `main`:

```bash
npm run sync-version          # при необходимости
npm run rustore:cap:build     # → rustore/dist/app-release.apk
```

В Консоли → Новая версия → загрузить APK → «Что нового» из `listing.ru.md`.

Проверить на телефоне:
- [ ] AI пишет в рацион / план (не только чат)
- [ ] Фото в AI → правка КБЖУ → подтверждение
- [ ] Офлайн → очередь → Отправить / Убрать
- [ ] Зал Today: один CTA / «День отдыха»
- [ ] План → Итог недели → «Разобрать с AI»
