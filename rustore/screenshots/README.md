# Скриншоты для RuStore

## Готовый набор для загрузки

Папка `submit/` — вертикальные **1080×1920** PNG (9:16):

| Файл | Содержание |
|------|------------|
| `submit/01-hero.png` | Герой лендинга + заголовок витрины |
| `submit/02-features.png` | Как это работает / распознавание |
| `submit/03-cta.png` | Бесплатный старт / CTA |
| `submit/04-barcode.png` | Добавить еду → штрихкод (сканер на устройстве) |
| `submit/05-stats.png` | Статистика: инсайт + калории по дням |

Иконка витрины: `../icon-512-store.png` (512×512, без прозрачности).

В Консоль грузите **≥3**, лучше все 5 из `submit/` по порядку.

## Что ещё можно доснять

С демо-аккаунта в APK/TWA или PWA:

1. Рацион: кольцо дня + 2–3 записи  
2. Карточка проверки после фото (порция / уверенность)  

Без чужих логотипов крупным планом.

Сырые/промежуточные кадры лежат рядом (`*-1080.png`, `01-landing.png` и т.д.) — для справки.
