# Скриншоты для RuStore

## Готовый набор для загрузки

Папка `submit/` — вертикальные **1080×1920** PNG:

| Файл | Содержание |
|------|------------|
| `submit/01-hero.png` | Герой лендинга + заголовок витрины |
| `submit/02-features.png` | Как это работает / распознавание |
| `submit/03-cta.png` | Бесплатный старт / CTA |

Иконка витрины: `../icon-512-store.png` (512×512, без прозрачности).

## Что ещё снять с телефона (обязательно перед модерацией)

С демо-аккаунта в установленном APK/TWA или PWA:

1. Рацион: кольцо дня + 2–3 записи  
2. Карточка проверки после фото (порция / уверенность)  
3. Экран добавления: фото / текст / штрихкод  

Без чужих логотипов крупным планом. Заменить ими `submit/02` и добавить как 4–5-й кадр.

Сырые захваты браузера лежат рядом (`01-landing.png` и т.д.) — для справки, не обязательно грузить в Консоль.
