# RuStore: отказ «WebView / нет сети» + ответ модератору

## Что изменилось с прошлой подачи

1. **Убран remote `server.url`** — cold start только из assets APK (`rustore/cap-www/`).
2. Локальные экраны без сети: splash → welcome → демо-рацион и демо-тренировка.
3. Камера устройства из оболочки.
4. **Тренировки открыты всем** (не только админам).
5. **Офлайн-заглушка** (`offline.html` + `server.errorPath`): при разрыве сети или ошибке
   загрузки удалённой страницы WebView показывает фирменный экран приложения, а не
   системную ошибку «веб-страница недоступна».
6. Кнопка «Войти» при реальном отсутствии сети открывает ту же заглушку
   (проверка через запрос к calorievision.ru, не через `navigator.onLine` —
   WebView часто врёт «офлайн»).

Сборка:

```bash
npm run rustore:cap:init
npm run rustore:cap:build
# → rustore/dist/app-release.apk
```

Проверка офлайн:

1. Удалить старое приложение → поставить новый APK.
2. Авиарежим → welcome и демо-рацион открываются.
3. Нажать «Войти» в авиарежиме → экран «Нет интернета» (не Chrome/WebView error).
4. Включить сеть → «Повторить» / открыть черновик.

1) Локальный старт приложения
Приложение открывается из состава APK (splash, онбординг, демо-дневник и демо-зал)
без обращения к сайту. Сайт calorievision.ru — веб-версия для синхронизации

показывается системная ошибка веб-страницы. Пользователь видит экран приложения
«Нет интернета» с понятным текстом и кнопками: повторить подключение или открыть
локальный черновик на устройстве.

Просьба рассмотреть обновлённую версию <укажите versionName / versionCode из APK>.

С уважением,
команда Calorie Vision
support@calorievision.ru
