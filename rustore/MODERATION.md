# RuStore: отказ «WebView» + ответ модератору

## Что изменилось с прошлой подачи

1. **Убран remote `server.url`** — cold start только из assets APK (`rustore/cap-www/`).
2. Локальные экраны без сети: splash → welcome → демо-рацион и демо-тренировка.
3. Камера устройства из оболочки.
4. **Тренировки открыты всем** (не только админам): журнал зала в том же продукте.
5. Лендинг и карточка витрины обновлены: питание + тренировки.

Сборка:

```bash
npm run rustore:cap:init
npm run rustore:cap:build
# → rustore/dist/app-release.apk  (version из package.json, сейчас 2.2.8)
```

Проверка: удалить старое приложение → поставить APK → **авиарежим** → welcome и демо-рацион/зал.
